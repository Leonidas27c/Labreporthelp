## Für Windows 10/11: einfach herunterladen und starten

1. Unten bei „Assets“ **Labreporthelp-windows.zip** herunterladen.
2. Rechtsklick auf die ZIP-Datei → „Alle extrahieren“.
3. Im Ordner **„Labreporthelp starten.bat“** doppelklicken.
   Meldet Windows „Der Computer wurde durch Windows geschützt“: „Weitere Informationen“ → „Trotzdem ausführen“.
4. Beim ersten Start werden Git und Claude Code eingerichtet, dann meldest du dich mit deinem Claude-Konto (Pro oder Max) an.
   Danach öffnet sich Labreporthelp im Browser, und auf dem Desktop liegt eine Verknüpfung.

Claude Desktop verbinden (MCP): Claude Desktop installieren und anmelden, dann **„Claude Desktop verbinden.bat“** doppelklicken und Claude Desktop neu starten. Details stehen in LIESMICH.txt.

Updates: Ab dieser Version prüft „Labreporthelp starten.bat“ beim Start, ob es eine neuere Version gibt, und installiert sie automatisch. Deine Einrichtung bleibt erhalten.

Neu: Angehängte Versuchsanleitungen (PDF, Word, PowerPoint, Excel) werden vor dem Chat mit Microsoft markitdown in Markdown umgewandelt, damit Claude Überschriften und Tabellen sauber erkennt.

Node.js und Python (mit markitdown) sind im Paket enthalten, du musst nichts weiter installieren.
Die Dateien „Source code (zip)“ brauchst du nicht, die sind nur für Entwickler.
